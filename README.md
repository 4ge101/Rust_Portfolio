# Alix Sami — Terminal Portfolio

A personal portfolio that runs directly in the terminal.

Built with Rust as a native TUI. No browser, no server.

## Install

### Linux / macOS

```bash
curl -fsSL https://raw.githubusercontent.com/4ge101/Rust_Portfolio/main/install.sh | sh
```

### Windows

```powershell
irm https://raw.githubusercontent.com/4ge101/Rust_Portfolio/main/install.ps1 | iex
```

You can also download the binary directly from [Releases](https://github.com/4ge101/Rust_Portfolio/releases).

## Run

```bash
alixsami
```

```bash
alixsami --help
alixsami --version
```

## Controls

* `↑` / `↓` or `j` / `k` — move
* `Enter` — select
* `Esc` — back
* `1`–`7` — jump to a section
* `:` — command palette
* `?` — help
* `q` — quit
